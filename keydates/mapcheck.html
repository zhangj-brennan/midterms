Map vs. Data Check

For each state: exactly what the map does with each row of the data. This page runs the map's own code (map_logic.js) on the same CSV, so it can't drift from the map. Line numbers are lines in state_dates_2026.csv.

The map uses the data in two ways:

  • Tile shading and the "Today" legend use at most one date per state per deadline type: registration deadlines from VOTE411 (Election Day dates left out); the latest same-day registration end (Election Day left out); the first dated mail ballot request row; the latest emergency ballot period end; the earliest early voting start and latest end (from "Early Voting" rows; in-person absentee rows only when a state has none); the latest non-postmark ballot return date; and the first "Postmarked" return row.
  • The hover popup shows nearly every row, except U.S. Vote Foundation registration rows other than same-day / Election Day registration (VOTE411's by-method dates are shown instead).
